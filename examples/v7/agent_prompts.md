# Copyable prompts for your existing researcher agent

## Prepare

```text
Read Quarry's V7 methods, study contract and adapter docs. Help me specify H1 on
new expressions and contextual senses. Include negative, long and multilingual
sources where relevant. Group translations/reposts/threads. Freeze held-out
families before tuning and keep gold outside your planning workspace. Compare
mixed union and Specialists against development-selected repeated general at
an equal resource envelope. Draft the JSON and validate it; show unresolved
research choices. No paid calls, model downloads or allocations are authorized.
```

## Freeze and execute after separate real-experiment authorization

```text
Show the current contract, configuration/software/prompt/model hashes, source
hashes and splits, rubric, repetition seeds, planned order, cache regime, finite
limits and stopping rules. Freeze only after the researcher resolves them.
The spec does not authorize execution. When execution is separately authorized,
keep each arm in fresh state, meter actual internal calls/retries and retain all
source outcomes. Preserve uncertain reservations and stop at approved caps.
```

## Semantic review and effort

```text
Create a blinded assisted complete-source packet. Display full source text and
original locations. Label model suggestions separately. Record eligibility,
contextual meaning, definition support and translation judgments with reasons.
Keep uncertain, disputed and unscorable judgments. Let the reviewer add omissions
and reverse decisions. Use a shared exposure registry, disjoint unseen families
and pause-aware active timing; do not repeat a source to manufacture time savings.
```

## Score and hand off

```text
Lock prediction hashes before reading external independent adjudicated gold.
Report occurrence and source-term detection separately from human semantic axes.
Include negative/failed/pending/partial/uncertain sources, false negatives,
domain/language breakdowns, paired family intervals and null metric reasons.
Recompute frozen reports without provider calls. Clearly separate software checks,
proposed hypotheses and empirical results. Do not publish collected data.
```

## Student / formative usability task

```text
Prepare a dry-run task and pseudonymous measurement log for setup completion,
active time, interventions, agent correction loops and scope/evidence/billing
understanding. Record harness/model, experience, task difficulty, help policy,
order and family exposure. Compare an appropriate direct workflow with its
available agent skills. Participant recruitment needs separate authorization.
```

## GT platform preparation

```text
Prepare an inert GT bundle controlled by my existing agent. Record checkpoint
hash, runtime/version, quantization, hardware and concurrency with unknown reasons.
Leave site configuration to the institutional operator. Prepare accounting for
allocation hours, queue/startup, throughput/memory, checkpoint/recovery overhead.
Keep measured allocation cost distinct from token estimates and unknown infrastructure.
Do not submit, download weights or start persistent services.
```

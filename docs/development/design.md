# Quarry visual identity

Quarry follows the clear wordmark and prompt-first hierarchy of the
[Paper2Agent GitHub page](https://github.com/jmiao24/Paper2Agent), with its own
original strata mark and a warm palette. The project artwork uses ivory,
terracotta, peach, amber and warm charcoal; it does not copy Paper2Agent's logo.

| Role | Color |
| --- | --- |
| Canvas | `#FFFCF7` ivory |
| Main text | `#3A2C24` warm charcoal |
| Brand accent | `#A64B2A` terracotta |
| Collector operations | `#F8E6D8` pale peach |
| Human steps | `#FFF0CF` pale amber |
| Other nodes | `#F6EDE4` warm stone |
| Borders | `#D6BFAE` stone |
| Secondary text | `#705444` taupe |
| Arrows | `#95745E` brown |

The banner keeps one wordmark and one short message. Workflow cards use fewer
columns and larger text. Below 760px, the README selects a separate vertical
workflow image; its numbered steps and research meaning match the wide version.
Mermaid diagrams use explicit node, cluster and edge styles instead of relying
on default blue or purple fills. Their labels and connections remain unchanged.

Keep text and numbered steps as well as color. Human-step coloring identifies
a role, not approval, authentication or correctness. Preserve SVG titles and
descriptions, original evidence distinctions and the complete-source evaluation
requirement. Project artwork has an opaque background for consistent readability
in GitHub's light and dark appearances. GitHub controls its surrounding interface.

When changing the artwork, inspect both 360px and 1024px layouts, verify the
responsive image choice, check text bounds, and maintain readable contrast.
Keep collector behavior and research policy independent of visual changes.
